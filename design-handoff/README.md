# Clash of Trades design handoff

Start with the [game art gallery](gallery/game-art.html). Open the HTML locally to compare buildings at landscape phone scale, inspect details, and replay the scaffold removal. The [art archive](gallery/game-art-archive.html) contains earlier visual studies.

The [designer handoff](DESIGNER_HANDOFF.md) is the November 26, 2026 prototype baseline. The gallery records subsequent art proposals, including the neighborhood-bank interpretation of the ETC and BTC collectors and the Marketplace exterior used for Town Hall.

| Folder | Contents |
| --- | --- |
| [District artwork](assets/district/) | Both levels of all three buildings, tray and unlock atlases, shared scaffold, and comparison streets |
| [Game artwork](assets/game/) | Marketplace, envelope, district, Exchange interiors, traders, trading chip, and earlier game sprites |
| [Chapter One](assets/chapter-one/) | Second-counter Marketplace interior study |
| [Gallery](gallery/) | Current and archived art, plus the Exchange chart walkthrough |

Each district building occupies a 3 × 3 plot. The street studies use the same landscape camera. The construction replay illustrates the visual transition after an upgrade is confirmed. Wallet balances, production rates, timers, and transaction states belong in the UI.
