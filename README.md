# Frontend-COT

Mobile frontend for a 2D isometric village game that teaches perpetual
futures through paper-trading lessons.

## Project status

Planning and prototyping.

Android is the first development and testing platform. iOS support is
planned afterward.

## Planned technology

- Godot
- Typed GDScript
- HTTPS and secure WebSocket communication with our backend

## Responsibilities

This repository will contain:
- Village presentation and interactions.
- Trading screens and account-state presentation.
- Interactive lessons and execution explanations.
- Challenge interfaces supporting automated opponents and future players.
- Graphics, animations, and mobile input handling.

The backend owns trading calculations, virtual balances, outcomes,
and rewards.

## Documentation

Detailed architecture, module boundaries, and known limitations will be
maintained in `docs/architecture.md`.

Build and setup instructions will be added alongside implementation.
